التغييرات تُحفظ في ملفات المشروع على الكمبيوتر. لمشاهدتها فورًا شغّل npm run edit. تحديث النسخة المنشورة يحتاج رفع الملفات إلى GitHub ليُعاد نشرها على Vercel.PNG / JPG / WebP حتى 12MB. للشعارات استخدم PNG بخلفية شفافة. تُحفظ نسخة احتياطية من المحتوى قبل كل تعديل.
